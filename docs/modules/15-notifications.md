# Notifications

**Owns:** SMS and email templates, and the record that a message was handed to a provider.  
**Service:** `notification-service`.  
**Does not own:** the decision that an order is paid or shipped. It consumes events and sends.

Push is phase 2. WhatsApp is optional and not required for version 1.

---

## Messages in version 1

| Trigger | Channel | Who |
| --- | --- | --- |
| OTP requested | SMS | Customer or the number on the form |
| `OrderConfirmed` | SMS | Customer |
| `ShipmentBooked` | SMS | Customer, includes AWB |
| `ShipmentUpdated` to delivered | SMS | Customer |
| `RefundCompleted` | SMS | Customer |
| Seller `kyc_rejected` or `approved` | Email | Seller owner |
| New order in a seller group | Email | Seller orders role |
| Staff invite, password reset | Email | That person |

Marketing SMS is not sent unless the customer’s `marketing` consent is on. Order SMS uses the `order_sms` consent collected at registration. OTP is part of signing in and does not need a separate marketing consent.

---

## India SMS

Commercial SMS in India goes through a DLT-registered principal entity, a registered sender id, and a registered template. Each template row stores the DLT template id and the variables it may fill (order id, AWB, amount in rupees). The sender cannot put a free-text body into a transactional template.

| Environment | Behaviour |
| --- | --- |
| Dev | Write the message to the log, including OTP, so an engineer can sign in. |
| Stage | Send only to phone numbers on an allow-list. |
| Prod | Send. The log stores provider message id, template id, and delivery status. It does not store the OTP, the full phone, a PAN, or a bank account. |

---

## Delivery record

| Field | Meaning |
| --- | --- |
| `template` | Which message |
| `to` | Phone or email, masked in logs |
| `providerMessageId` | For a support lookup |
| `status` | `queued`, `sent`, `delivered`, `failed` |
| `eventId` | The domain event. A duplicate event does not send a second SMS. |

A provider failure retries from the queue. It does not roll back the order. The customer can still see status in the app. After the retries are exhausted, the message sits on the notification dead-letter queue and the admin home queue shows a count.

---

## Email

Seller and staff email uses SES or another provider called only by this service. The same event-id rule applies. Password-reset links are single use and are generated by identity. Notification only delivers them.
